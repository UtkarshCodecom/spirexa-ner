⚡ Why does the dashboard load in under a second? — and does it really check all hotspots live? ▼
Pre-computed snapshot
compute_live_risk.py scores all 311 hotspots in one batch run (~60 s, using cached satellite data from Google Earth Engine). Results are written to live_risk.csv once. The dashboard reads that file — it does not re-run the model on every page load.
Static HTML serving
build_dashboard.py bakes every data point (risk scores, geo paths, case studies) directly into a single 672 KB HTML file as inline JSON. The server just streams that file — no database query, no templating at runtime. Typical serve time: < 50 ms.
"Check any point" is live
The Check any point probe in the sidebar is the exception: it fires a real Earth Engine query for that exact coordinate and date, so it takes 3–8 seconds. That is the model actually running, not reading a cache — which is why it gives real, current numbers.

SPIREXA Roadmap

From SIH prototype to production early-warning infrastructure for the eight NER states

🔩 Hardware & Sensors
ESP32 field node (v1)
Soil moisture, rain gauge, DHT22 temperature & humidity, soil-wetness sensor. USB-powered lab prototype reporting over Wi-Fi.
Live
Solar + Li-ion battery pack
18650-cell pack with MPPT charge controller. Target: 30-day autonomous standby. PCB layout under test.
Building
LoRa SX1276 offline radio
15 km range, no SIM card. Mesh relay from deep-valley nodes to a base station where 4G is absent. Critical for NER terrain.
Planned
MPU-6050 3-axis accelerometer
Detects slow slope creep at mm-scale displacement — days before visible cracking. Most shallow slides telegraph themselves first.
Planned
Soil tensiometer
Pore-water pressure is the direct physical trigger for most shallow slides. Satellite soil moisture is an 11 km average; this measures the real thing, on-slope.
Research
🧠 Intelligence & Models
RF / XGBoost ensemble
Trained on 318 NER events (2007-2025). ROC-AUC 0.933. Features: GPM rainfall, SMAP soil moisture, SRTM slope, factor-of-safety, road proximity.
Live
LSTM 48-hour ahead forecast
Deep learning on 7-day GPM rainfall time-series to predict slide probability two days out — giving evacuation teams an extra window before the event.
Building
Fine-tuned LLM response advisor
On confirmed SEVERE alert: generates a prioritised action checklist for the District Collector — road closures, evacuation zones, NDRF positioning — grounded on NER disaster-response SOPs. No hallucination: output is template-constrained.
Planned
Post-slide SAR damage mapping
Sentinel-1 SAR change detection + CV model to automatically map affected area within 6 hours of an event — replacing manual overflights that can take days in NER terrain.
Planned
Sensor-fusion model (v2)
Combine ground node readings (soil moisture pct, tilt) with satellite features as additional inputs. The on-slope measurement should sharply reduce false positives in complex terrain.
Planned

311 hotspots across 8 NER states. Pre-computed snapshot, sub-second load, pan & zoom map, hindcast validation.
Live

Live
Offline field reporting
Field teams submit hazard reports with photo, GPS location and hazard type. Reports queue in IndexedDB if there is no signal and upload automatically on reconnect.
Live

One-click send from the dashboard to registered district officer numbers. Message templates pre-approved by Meta for emergency use.
Building

Planned
