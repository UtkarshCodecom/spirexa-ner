Scenario

Physics-informed — the WCN (Weighted Curve Number) engine computes direct runoff from today's rainfall and antecedent moisture condition. That estimate is a feature in the gradient-boosting model alongside discharge lags and seasonal encodings.

API (Antecedent Precipitation Index) is the top weather predictor — it captures soil memory that a single-day rainfall feature misses.

About this model

Architecture: HistGradientBoosting (sklearn XGBoost-equivalent)
Target: log₁p(discharge) → back-transformed at inference
Horizons: +1 to +7 days, separate model per horizon
Uncertainty: p10/p90 quantile regression
Training data: 12 years synthetic (WCN physics + AR noise)

LSTM / KAN upgrade: the feature matrix is already structured for sequence models. Replace HGBR with a PyTorch LSTM or KAN (see src/discharge.py, "LSTM / KAN upgrade path").

Real data integration: swap generate_training_data() for an IMD/CHIRPS + CWC WRIS gauge loader (see scripts/train_discharge.py).
